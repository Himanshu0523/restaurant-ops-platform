# 👤 User Module

Central **identity and profile** layer for the Servio platform. Authentication tokens are generated by `AuthModule`; this module manages who the user is.

## Endpoints

| Method | Route | Description | Auth |
|--------|-------|-------------|------|
| GET | `/users/me` | Get own profile (safe) | JWT |
| PATCH | `/users/profile` | Update display name, phone, avatar | JWT |
| PATCH | `/users/preferences` | Update dietary, allergens, language | JWT |
| PATCH | `/users/:id/role` | Change a user role | Admin |
| PATCH | `/users/:id/status` | Suspend / activate account | Admin |
| DELETE | `/users/:id` | Soft-delete account | Admin |

## Schema Fields

| Field | Type | Notes |
|-------|------|-------|
| `email` | String | Unique, indexed |
| `password` | String | bcrypt hashed |
| `refreshTokenHash` | String | Hashed refresh token |
| `displayName` | String | |
| `phone` | String | |
| `emailVerified` | Boolean | |
| `role` | UserRole | PLATFORM_ADMIN, OWNER, MANAGER, STAFF, CUSTOMER |
| `status` | UserStatus | ACTIVE, SUSPENDED, PENDING_VERIFICATION |
| `tenantId` | ObjectId | null = platform-level |
| `preferences` | UserPreferences | Sub-document |

## UserRole Hierarchy

```
PLATFORM_ADMIN > OWNER > MANAGER > STAFF > CUSTOMER
```

## `toSafeUser()`
Strips sensitive fields before returning to client:
- Removes: `password`, `refreshTokenHash`, `__v`
